1. 前置条件

48 小时内不做高强度腿部训练；测试场地固定；鞋、天气、热身流程保持一致。每次都必须全力完成，误差记录到 0.1 秒。

2. 距离与日程安排

Day 1：1200m 全力（约 3-5 分钟）；Day 2：休息或极低强度恢复；Day 3：2400m 全力（约 6-10 分钟）；Day 4：休息；Day 5：3600m 或 5000m 全力（约 11-20 分钟）。单次力竭时间优先落在 2-15 分钟。

3. 计算方式

用 距离作为 y、完成时间作为 x 做线性回归。斜率是 CS（m/s），截距是 D'（m）。示例：1200m 3:45、2400m 7:50、3600m 12:00 —— CS 约 4.84 m/s，配速约 3:27/km，D' 约 112m。

4. HYROX / 比赛转译

CS 不是整场巡航速度。对于多站混合赛（如 HYROX），模型默认用 CS × 0.95 估算巡航速度，再结合 LTHR 和站点后恢复窗口微调。纯跑项目直接用 CS 作为起点配速。

实验室递增测试（金标准）

跑台从低强度开始（如 8km/h）；每 3 分钟增加 1-1.5km/h；每级负荷结束前 10 秒采血并记录心率；直到血乳酸明显上升或力竭。LT2/MLSS 对应心率用于设定比赛红线——超过此心率乳酸将快速累积，只能维持 30-60 分钟。

30 分钟场地法（实用替代）

充分热身后进行 30 分钟全力均速跑。取后 20 分钟平均心率作为 LTHR 近似值。注意：短于 20 分钟容易受无氧供能干扰，长于 60 分钟会被肌肉疲劳污染。测试应在田径场或稳定路线上完成。

器械修正

Row / Ski 的 LTHR 通常可按跑步 LTHR 下调 3-5 bpm。示例：若跑步 LTHR 为 175 bpm，划船超过 170 bpm 就应视为红线附近。不同器械涉及不同肌群和体位，心率-负荷关系存在差异。

安全与质量控制

同一设备、同一热身、同一补给状态；测试中出现胸痛、明显眩晕、异常心律或无法维持动作安全时立即终止。静息心率连续 3+ 天升高超过 5 bpm 时推迟测试。

静息心率（RHR）

连续 3-5 天起床后、未下床前测量，取稳定均值。睡眠不足、饮酒、发热和高压日的数据应剔除。波动超过 ±3 bpm 时延长采集天数。

最大心率（MHR）

优先使用真实递增测试结果（推荐方案）。没有实测值时，用 208 − 0.7 × 年龄 作为临时估算——这比传统的 220 − 年龄更适合健康成人，但不替代实测。实测方式：充分热身后 3-4 次 2 分钟最大上坡冲刺，取出现过的最高心率。

Karvonen 公式（储备心率法）

目标心率 = 静息心率 + (最大心率 − 静息心率) × 强度百分比。Z2、阈值、红区暴露都应回到这个公式，而不是只看最大心率百分比。HRR 法比单纯 %MHR 更准确。

比赛策略：从数据到每一站的决策

核心技术问题

通过 CS 确定配速锚点，通过 LTHR 确定心率封顶（比赛中不超过此值），通过 HRR 确定恢复心率窗口（站点后应回到哪个区间）。三者整合后，每一站的策略就有了数据依据而不是"凭感觉"。

配速策略模板（以 HYROX 8×1km 为例）

Run 1：CS × 0.90-0.93（保守开局，心率建仓）；Run 2-3：CS × 0.93-0.96（找到巡航节奏）；Run 4-6：CS × 0.95-1.00（核心巡航段）；Run 7-8：视 D' 剩余量和心率状态决定是否提速。站点后 200m 用小步频恢复跑姿，不要急于回到目标配速。

站点→跑步过渡判断

Ski 后看 Run 2 的踏空感（心率高但动作轻飘）；Sled Push 后看 Run 3 步频是否骤降（股四头肌疲劳）；Sled Pull 后站直看是否眩晕（体位性低血压）；Row 后看 Run 6 大腿再灌注；Farmers Carry 后看呼吸和步频是否脱节（膈肌疲劳）。如果站点后 400m 跑步段 CV > 6%，说明策略或动作效率有问题。

D' 实时管理

高于 CS 的每一秒都在消耗 D'。比赛初期不要挥霍 D'（开局压速），中期可适度提取（追上目标时间），末期清空 D'（全力冲线）。低于 CS 跑时 D' 会缓慢恢复——站点和恢复跑都是 D' 的充电机会。

各指标含义详解（新手必读）

核心指标

CS — 临界速度 (Critical Speed)

定义：你能理论上无限维持的最高跑步速度。

生理本质：此时身体产生乳酸 = 清除乳酸，乳酸不再累积，是可持续跑的边界线。

  • CS ≈ 最大乳酸稳态 (MLSS)
  • CS ≈ 马拉松/半马比赛配速
  • CS ≈ 最大心率 88-92%

怎么提升：慢跑堆量（线粒体↑）+ 节奏跑（乳酸清除↑）+ 长距离

核心指标

D' — 无氧距离储备

定义：高于 CS 时你能额外跑出的总距离，像一块"无氧电池"。

生理本质：磷酸原 + 糖酵解系统的总容量。速度超出 CS 越多，电池消耗越快。

  • 耗尽时间 t = D' / (当前速度 − CS)
  • 低于 CS 跑时，D' 缓慢恢复
  • 800/1500m 选手 D' 通常很大

怎么提升：短间歇冲刺 + 力量训练 + 高强度间歇

教练必读

CS 与 D' 的权衡关系

同一个运动员，CS 和 D' 往往负相关——你很难同时拥有极高的 CS 和极大的 D'。

  • 耐力型（如马拉松选手）：CS↑↑↑ / D'↓
  • 速度型（如 800m 选手）：CS↓ / D'↑↑↑
  • 全能型（极罕见）：CS↑ / D'↑

训练必须根据项目距离权衡二者投入比例。

质量控制

R² — 拟合优度

定义：测试数据的线性拟合程度，范围 0-1。越接近 1 说明数据越可信。

  • R² ≥ 0.98：数据非常可靠，CS/D' 精确
  • 0.95 ≤ R² < 0.98：可用，有小波动
  • R² < 0.95：数据不稳定，建议重新测试

不稳定的原因：距离太接近、未全力跑、或测试间隔过短。

心率指标

LTHR — 乳酸阈值心率

定义：乳酸开始快速累积时的心率，约为你全力维持 60 分钟的最高心率。

  • 比赛红线：超过 LTHR = 进入倒计时
  • 30 分钟场地法：后 20 分钟均值
  • 划船/滑雪 LTHR ≈ 跑步 LTHR − 5

用途：比赛中用 LTHR 封顶，不超此心率就不会提前"爆缸"。

心率指标

HRR — 储备心率 (Karvonen)

定义：考虑静息心率的个性化强度计算方式。

公式：目标心率 = RHR + (MHR − RHR) × 强度%

  • 比单纯 %MHR 更准确
  • 静息心率越低，训练窗口越宽
  • Z2 训练对此公式尤其敏感

用途：训练课强度设定（不像 LTHR 那样用于比赛红线）。
