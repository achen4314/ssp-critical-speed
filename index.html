🏃

HYROX 的独特挑战

HYROX 是 8 次 1km 跑步 + 8 个功能站点 交替进行。跑步段需要巡航能力，站点会改变代谢、局部肌肉和动作成本，然后你还得立刻重建跑步节奏。这不是纯跑比赛——配速必须为后续站点和转换留余量。

🔋

CS = 速度模型锚点

临界速度 (CS) 是由多距离极限成绩拟合出的速度—时间模型边界，仍然只可有限维持。在 HYROX 中，站点会改变后续跑步成本；本站用 CS 的一定比例给出巡航建议起点，再由完整模拟校准。

⚡

D′ = CS 以上模型容量

无氧距离储备 (D′) 是速度—时间模型中 CS 以上的有限距离容量，可作为“冲刺电池”的沟通比喻，但不等同于一块可直接测量的无氧能量。恢复速度受低于 CS 的强度、持续时间和疲劳背景影响。

❤️

LTHR = 场地阈值心率锚点

LTHR 是特定测试协议下的阈值心率近似，不是一次越过就必然“爆缸”的绝对红线。HYROX 中可用它限制长时间高强度暴露，并结合配速、RPE、动作质量和后程掉速判断策略。

举个例子：你的 CS 是 4:00/km，模型可先给出约 4:12/km (CS×0.95) 的跑段建议起点；再用全流程模拟检查站点后掉速、心率走势和动作质量，决定是否需要继续下调或分段调整。

雪橇、排队与数据污染

  • 雪橇可用目标比赛组别负重，但第一轮必须动作连续、技术稳定、无需多次停顿；否则本课主要反映绝对力量。
  • 场地摩擦差异大，必须记录雪橇总负重、雪橇/草皮、Ski 设置、Wall Ball 重量与目标高度。
  • 起跑间隔应覆盖所有单通道器械的占用时间并留缓冲；若 Ski 250m 超过 75 秒，改 90 秒或启用第二台。
  • 任何排队、器械更换、路线错误、漏做、动作标准改变或计时错误，都要把该轮标为“受污染”。

强度控制与记录口径

跑步与 RPE

  • 本课跑步目标：个人预计 HYROX 比赛配速慢 5–10 秒/km；前三轮控制在目标值 ±5 秒/km，换算到 800m 即 ±4 秒。
  • R1 约 7/10，R2 为 7–8，R3 约 8，R4 最高 8.5；R1 RPE ≥8 且后程有损耗时，优先复核起步策略。
  • 有跑步 LTHR 者，前两轮平均心率尽量不超过其附近；LTHR 只作观察锚点，不是安全阈值，也不临场追心率。
  • 没有心率时使用配速＋RPE，数据仍有效。

心率与站点时间

  • 只比较每段 800m 平均心率，不使用握器械或拉雪橇时的瞬时腕式光电心率；胸带优先。
  • “站点总时间”从 800m Lap 结束开始，到第 15 个有效 Wall Ball 完成为止，包含器械间转换。
  • 跑段平均心率变化 ΔHR = 平均(HR3, HR4) − HR1；它不是标准稳态心率漂移/解耦测试。
  • 仅当后两轮平均跑步时间相对 R1 的绝对差异 <3%、环境近似且心率完整时，ΔHR 才辅助解读。

LTHR 阈值心率测试

方法一：30 分钟场地法（无需设备，最实用）

充分热身后，进行 30 分钟全力均速跑。取后 20 分钟的平均心率，这就是你的 LTHR 近似值。例：后 20 分钟心率在 172-178 → LTHR ≈ 175。

方法二：实验室乳酸 / 气体交换测试

采用与能力匹配的递增协议，在各级记录心率、气体交换，并按预先选定的方法采血分析乳酸曲线。不同阈值判定法可能给出不同结果，因此报告中要保留协议与判定标准，而不是把某个“明显上升点”直接等同 LTHR。

专项差异

跑步、划船和 SkiErg 的参与肌群与姿势不同，心率锚点可能不同。不要套用固定 bpm 修正；如需跨器械处方，应分别完成标准化测试。

⚠️ 安全边界

测试中出现胸痛、晕眩、近乎晕厥或异常心悸 → 立即停止并根据情况寻求医疗评估。若晨起心率、睡眠、主观疲劳或感染症状连续异常，先推迟最大测试并复核。

心率储备 HR Reserve（个性化训练区间）

静息心率 (RHR)

连续 3–5 天早晨醒来未起床时测量，建立个人均值。酒精、失眠、感染、训练负荷和测量姿势都会影响结果；单日高低不等同于“恢复好坏”，应结合主观状态看趋势。

最大心率 (MHR)

公式：208 − 0.7 × 年龄是人群层面的年龄估算，个体误差可能较大；有合适测试条件时优先使用专项递增测试中的实测峰值。

Karvonen 公式

目标心率 = RHR + (MHR − RHR) × 强度%。这比直接用 %MHR 更个性化——静息心率越低，训练窗口越宽。

不要与 HR Recovery 混淆

HR Reserve 用于估算训练区间；HR Recovery 是停止运动后 1–2 分钟的心率下降。中文都常简称“HRR”，本站后者统一写作 HRR1 / HRR2。

VT1 / VT2：现场锚点与实验室确认

VT1 / VT2 应由递增运动中的气体交换确认。没有实验室时，标准化 Talk Test 可以提供便捷的现场强度锚点，但不是对 VT1 / VT2 的直接测量；请记录配速、心率和说话等级并重复验证。

🧪 Talk Test — 建立低强度现场锚点

在跑台或平路从轻松强度开始，每 2–3 分钟小幅提速，每级末朗读同一段 30 字左右的句子并标记“舒服 / 不确定 / 不舒服”。最后一个“舒服”级别可作为轻松训练上限的建议起点。不要用固定 %HRmax 代替个人反应。

🧪 Talk Test — 观察上强度转折

继续按相同步长提速，记录从“不确定”到“不舒服、只能说少量词”的级别。这个转折可帮助约束阈值课强度，但不能单独命名为 VT2 或 MLSS。HYROX 巡航上限应同时参考运动专项 LTHR、CS、RPE 与完整模拟的后程表现。

🏃 有氧解耦 — 看耐久，不“确认 VT1”

先在 Talk Test 的轻松锚点下做 30–45 分钟稳态跑，再使用“恢复 / 耐久”页比较前后两半的速度—心率效率。≤3%、3–5%、>5%仅作为 SSP 内部观察带；先排查气温、坡度、配速、补液、补给和传感器，再决定是否增加 Z2 耐久训练。

⚠️ 注意事项

说话测试受句子、语言、测试者判断和疲劳影响；使用同一句话、同级时长、同提速步长，重复 2–3 次看稳定性。跑步、划船与 SkiErg 应分别建立心率锚点，不套用固定 bpm 修正。若需要确认 VT 或 MLSS，使用气体交换或多次恒负荷乳酸测试。

依据：Talk Test 可用于现场调节强度，但与乳酸阈和通气阈的对应并非完全一致（Quinn & Coons, 2011；Woltmann 等, 2015）；研究也提示 CS / CP 与 MLSS 不应互换（Dekerle 等, 2003）。

🏁 8 个跑段的出入站策略

目标不是每公里都跑快，而是在该恢复的地方恢复，在能拿回时间的地方拿回时间。

01 · Start → Run 1 → SkiErg

主题：开局配速与首站成本。Run 1 前 500m 不追随人群超速，进入 SkiErg 前仍应保留动作余量。首跑的 CS 比例只是建议起点；用呼吸、RPE 和完整模拟确认，避免把开局兴奋当作可持续能力。

02 · SkiErg → Run 2 → Sled Push → Run 3 → Sled Pull

主题：重新巡航与局部力量耐力。Run 2 先重建步频与呼吸，再进入 Sled Push；推后 Run 3 的前段优先找回步态，不抢配速。雪橇分段目标是稳定而非首段冲刺；拉雪橇时配合呼气，站直后若眩晕立即减速或停止。

03 · Sled Pull → Run 4 → BBJ → Run 5 → Row

主题：直立转换与动作节律。Run 4 保持可控进入 Burpee Broad Jump；用固定距离分段记录动作节律。BBJ 后的 Run 5 可作为受控重建段，但是否主动降速应由个人目标、呼吸、RPE 与下一站 Row 的执行质量共同决定。

04 · Row → Run 6 → Farmers Carry

主题：划船后步态重建。离开 Row 后先用短步、放松上肢恢复跑姿，再逐步回到个人巡航范围。不要用固定 %HRmax 代替专项锚点；若同配速心率、RPE 与动作成本同时异常升高，先降速并复核环境和划船输出。

05 · Farmers Carry → Run 7 → Sandbag Lunges

主题：握力、躯干稳定与呼吸重建。Farmer’s Carry 采用个人可控的短步与呼吸节律；进入 Run 7 后先放松肩颈、恢复自然摆臂，再为 Sandbag Lunges 保留动作质量。固定步频数字只可作为个体试验，不作通用要求。

06 · Sandbag Lunges → Run 8 → Wall Balls → Finish

主题：后程动作质量与最后一次跑站转换。弓步后 Run 8 的前段先重建步态，再按个人容量决定是否加速；完成 Run 8 后进入 Wall Balls，按预先验证的分组与呼吸方案收尾。墙球后直接完赛，没有第 9 个跑段。

教练决策框架：每个站跑转换看三点——① 配速是否回到个人目标范围？② 心率、RPE 与动作质量是否同步可控？③ SSP 内部容量情景是否仍与模拟趋势一致？三项都稳定，只能说明当前策略可继续观察，不代表已证明“最优”。

🚨 HYROX 最常见的5个翻车场景 + 补救策略

以下场景来自真实比赛数据和运动员反馈。提前知道这些坑，比赛时就能第一时间识别并补救。

🚨 翻车 #1：Run 1 超速（"比赛兴奋症"）

症状：跑完Run 1感觉很轻松，配速比计划快10-15s/km。心跳高但不觉得累。

可能方向：开局超出个人模拟范围可能放大后续心率、RPE 与动作成本，但不能把它直接换算成固定 D′百分比或必然掉速。

数据信号：Run 1-2配速 vs CS配速差异 >8% = 超速警告。Run 1心率 > LTHR − 10bpm = 开局过激。

补救（如果已经超了）：Run 2立刻降速到CS×0.85，Run 3再降回CS×0.82，牺牲2-3分钟换后面不崩。不要在Run 2继续"找节奏"。

🚨 翻车 #2：Sled Push 后 Run 3 步频崩溃

症状：推完雪橇后站起来觉得还行，但跑200m后步频从180骤降到160以下，觉得"腿灌了铅"。

后果：股四头肌离心疲劳导致跑步刚性丧失，跟腱弹性回馈消失，每一步都在"砸地"而非"弹地"。

数据信号：Run 3步频 < Run 1步频×0.9。Run 3平均配速 > Run 1配速 +20s/km。

补救：Run 3前200m故意用小步高频（200+spm）过渡，不追求配速。心率封顶LTHR+3bpm。如果步频不恢复，立刻切换为"生存模式"：CS×0.80，等Run 4恢复。

🚨 翻车 #3：BBJ 站点动作崩盘 → Run 5 "死亡跑"

症状：Burpee到第40-50m时单次耗时从4s变成6-7s，动作变形，站起时头晕。跑Run 5时感觉"每一步都在挣扎"。

可能方向：BBJ 动作节律、直立转换、前序配速与环境因素都可能影响 Run 5；不能用固定“D′消耗 30–35%”解释单次表现。

数据信号：按固定距离比较 BBJ 前后半节律，再看 Run 5 相对个人目标的偏差、RPE 与动作质量。心率越过 LTHR 不等同于 D′即将耗尽。

训练处理：先用 BBJ 分段和 BBJ → Run 5 串联确定个人可控节律；比赛中若多项信号同时恶化，临时降速重建动作。降速能否在后程拿回时间必须由完整模拟验证。

🚨 翻车 #4：Row 后 Run 6 "大腿再灌注"踏空

症状：划船时大腿剧烈充血，站起来跑Run 6时感觉"腿不是自己的"，前200m像踩棉花。

后果：血流竞争（划船时血液集中在大腿 → 站起来跑步时血液重新分配到全身）导致暂时的"假性无力"——不是真的没力，是血液还没回流。

数据信号：Run 6前200m配速比整段平均慢15s+/km = 再灌注延迟。心率在Run 6前400m异常高 = 心脏在补偿血液重新分布。

补救：Row 最后10次降低功率做"冲洗"。Run 6前200m用极短步幅（高步频180spm但不追求速度），给大腿30-45秒的再灌注时间。不要被"假性无力"骗了——2分钟后腿会回来。

🚨 翻车 #5：Lunges 后 Run 8 掉速 → Wall Balls 收尾碎裂

症状：弓步后 Run 8 步幅和躯干控制明显下降；进入 Wall Balls 后很快偏离预定分组，休息时间逐组拉长。

可能方向：可能同时包含弓步局部疲劳、Run 8 过早加速、墙球动作经济性与分组策略问题，不能只凭一个分段归因。

数据信号：比较 Lunges 前后分段、Run 8 相对目标的偏差，以及 Wall Balls 前 / 后半完成速率和中断次数；使用同组别、同球重和同动作标准复测。

训练处理：先分别验证弓步后受控跑与疲劳墙球，再做 Lunges → Run 8 → Wall Balls 的短流程串联。比赛中按已经验证的 Run 8 配速与墙球分组执行，不临场套用固定冲刺比例。

比赛中三问决策法：进入下一跑段后问自己——① 配速是否回到个人目标范围？② 心率、RPE 与动作是否共同可控？③ 当前走势是否仍符合完整模拟建立的容量情景？若多项持续偏离，先降速复核；不要把内部 D′预算当作可实时读取的生理电量。

各指标含义（每次比赛前回来看一眼）

核心

CS — 临界速度

由多个极限时长成绩拟合出的速度—时间模型边界，常用于描述严重强度域附近的跑步能力；它不是可无限维持的速度，也不能直接替代 MLSS 或 VT2。

  • 用于设定跑段速度与 D′ 策略锚点
  • HYROX 巡航比例是建议起点，需经模拟校准
  • 用同场地、同协议复测趋势
核心

D′ — CS 以上距离容量

速度—时间模型中高于 CS 的有限距离容量。“电池”是便于策略沟通的比喻，不能把站点能耗直接换算成真实 D′。

  • 恒速模型耗尽时间 = D′/(速度−CS)
  • 恢复具有强度与时间依赖性
  • 需与实际站跑模拟共同校准
心率

LTHR — 场地阈值心率锚点

特定专项和测试协议下的阈值心率近似，不是绝对“红线”。HYROX 中用它限制长时间超阈暴露，并结合配速、RPE 与后程表现调整。

  • 30 分钟场测：后 20 分钟均值作为近似
  • 跑、划、Ski 应分别建立锚点
区间

HR Reserve — 心率储备

HRmax − HRrest；Karvonen 目标心率为 RHR + HR Reserve × %。用于估算训练区间，不等于运动后心率恢复。

  • 最大心率估算会带来误差
  • 分区需用 Talk Test / LTHR / 实际训练校准
恢复

HRR1 / HRR2 — 心率恢复

负荷结束当刻心率分别减去 60 秒、120 秒心率。早期回落受副交感再激活影响，也受终点强度和恢复姿势影响。

  • 只比较同运动员、同协议趋势
  • 不用单次结果判断准备度或疾病
耐久

有氧解耦 — 短时效率漂移

比较稳态跑前后两半的“速度 ÷ 心率”效率。正值表示后半单位心率对应速度下降；高温、补液、补给、路线和传感器都可能影响。

  • 3% / 5% 是 SSP 内部观察带
  • 不能单次确认 VT1
权衡

CS 与 D′ 共同看

两者来自同一速度—时间模型，但个体变化并非固定跷跷板。训练决策应看绝对值、测试拟合、专项成绩与重复测试，而不是仅按“耐力型 / 冲刺型”贴标签。

质控

R² — 可信度

测试点拟合程度。≥0.98=可靠，0.95-0.98=可用，<0.95=重测。不稳定的原因：未全力跑 / 疲劳 / 条件不一致。
