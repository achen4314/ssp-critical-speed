HYROX 运动员的数据锚点 — CS / D' / LTHR / HRR 一站搞定

所有测试都服务于同一个问题：下一场比赛该用什么速度、什么心率、什么节奏进入每一站。

📖 如果你是 HYROX 新手，先读这里（3 分钟搞懂你在算什么）

🏃

HYROX 的独特挑战

HYROX 是 8 次 1km 跑步 + 8 个功能站点 交替进行。跑步段需要巡航能力（CS），站点消耗大量无氧能量（D'），然后你还得在站点后立刻回到跑步节奏。这不是纯跑比赛——你的配速必须为站点"留余量"。

🔋

CS = 你的巡航速度

临界速度 (CS) 是你永远不会累垮的最高速度。在 CS 以下跑，乳酸不会堆积。但在 HYROX 里你不能一直跑 CS——因为站点也要消耗能量。所以我们用 CS × 0.95 作为你的"HYROX 巡航配速"。

⚡

D' = 你的冲刺电池

无氧距离储备 (D') 是你高于 CS 时能额外跑出的距离。在每个站点后你需要加速回到配速——这就是消耗 D'。如果你的 D' 小，站点后就会掉速。D' 在低于 CS 跑时会慢慢恢复。

❤️

LTHR = 你的心率红线

乳酸阈值心率 (LTHR) 是你能维持约 60 分钟的最高心率。比赛中超过这个心率 = 进入倒计时 = 你会在 30-60 分钟内"爆缸"。HYROX 比赛中，你的心率会因站点反复冲高——关键是在跑步段把它拉回 LTHR 以下。

举个例子：你的 CS 是 4:00/km，但你在 HYROX 里的跑步段目标是约 4:12/km (CS×0.95)。因为你必须为 SkiErg、Sled Push、Wall Balls 这些站点保留能量。同时你的心率不能一直超过 175 bpm（你的 LTHR）——否则在 Run 5 之后你就会严重掉速。

LTHR 阈值心率测试

方法一：30 分钟场地法（无需设备，最实用）

充分热身后，进行 30 分钟全力均速跑。取后 20 分钟的平均心率，这就是你的 LTHR 近似值。例：后 20 分钟心率在 172-178 → LTHR ≈ 175。

方法二：实验室递增测试（金标准）

跑台从 8km/h 起，每 3 分钟 +1km/h。每级末采血测乳酸。乳酸明显上升的点对应的心率 = LTHR。这是最精确但需要设备。

器械修正

划船 / SkiErg 的 LTHR 通常比跑步低 3-5 bpm。如跑步 LTHR=175，划船时超过 170 就应警戒。

⚠️ 安全红线

测试中出现胸痛、晕眩、异常心律 → 立即停止。静息心率连续 3 天偏高超过 5 bpm → 推迟测试。

储备心率 HRR（个性化训练区间）

静息心率 (RHR)

连续 3-5 天早晨醒来未起床时测量，取均值。剔除喝酒、失眠、发烧日的数据。低于往常 = 恢复良好；偏高 >5bpm = 疲劳/生病。

最大心率 (MHR)

公式：208 − 0.7 × 年龄（比 220−年龄 更准，但仍是估算）。最佳：做递增测试测出真实最大值。

Karvonen 公式

目标心率 = RHR + (MHR − RHR) × 强度%。这比直接用 %MHR 更个性化——静息心率越低，训练窗口越宽。

三线交叉法

HRR → 训练课强度 | LTHR → 比赛心率红线 | CS → 速度锚点。三者交叉才能准确判断你的瓶颈在哪。

VT1 / VT2 通气阈测试（无需设备的小白友好方法）

通气阈 (VT) 是最古老也最好用的训练分区锚点之一。VT1≈有氧阈（能聊天→只能说短句的转折点），VT2≈无氧阈（只能说 1-2 个字→说不出话的转折点）。以下是三步骤简易方法。

🧪 说话测试 (Talk Test) — 找 VT1

在跑台上从走路开始，每 2 分钟提速 0.5 km/h。每一级结束时大声说一段 30 字的标准句子（如"我现在的配速感觉很轻松，可以一直跑下去"）。当你能完整说出但说完后需要吸一大口气——这就是 VT1。对应的配速 ≈ Z2 上限，心率 ≈ 65-75% HRmax。HYROX 应用：你的恢复跑和站点后过渡跑不应超过 VT1。

🧪 倒数说话测试 — 找 VT2

继续每 2 分钟提速。当你说出同一句话时，只能吐出 3-5 个字就必须换气——这就是 VT2。此时你还能说单词但不能说句子。对应的配速 ≈ 85-90% HRmax，与 LTHR 高度相关（但不完全等同）。HYROX 应用：VT2 是你的比赛巡航上限线——跑步段心率不应长时间超过 VT2。

🏃 心率漂移测试 (Cardiac Drift) — 验证 VT1

在疑似 VT1 配速下匀速跑 60 分钟。记录第 10 分钟和第 60 分钟的心率。心率上升 ≤5% → 确认 VT1 正确；上升 5-10% → 可能略高于 VT1；上升 >10% → 配速远高于 VT1，降速重测。这是验证训练分区准确性最简单有效的方法。

⚠️ 注意事项

说话测试受主观因素影响，重复 2-3 次取平均更可靠。不同器械（跑/划船/滑雪）的 VT1/VT2 心率不同——划船 VT 通常比跑步低 3-5 bpm。测试时保持标准化的说话内容、换气节奏和提速度步长。

🏁 8 个跑段的出入站策略

目标不是每公里都跑快，而是在该恢复的地方恢复，在能拿回时间的地方拿回时间。

01 · Phase 0 + Run 1 — SkiErg → 第 1 跑

生理主题：氧亏与 VO₂ 慢成分。0-500m 不超速，进站感觉应像"还能再跑 5km"。Ski 心率高不一定等于全身失控——上肢耗氧占比大但腿部仍相对新鲜。首跑用 CS×0.90，给心率建仓留空间。

02 · Run 2-3 — Sled Push / Pull → 第 2-3 跑

生理主题：Pi 积累、钙离子释放衰竭与升压反射。推雪橇分段波动控制在 10% 以内——第一段压住速度。拉雪橇每次发力配合强呼气，松手站直后视线平视远处固定点，避免 ROXZone 眩晕。跑步段目标 CS×0.93，找到巡航节奏。

03 · Run 4-5 — Burpee Broad Jump → 第 4-5 跑

生理主题：直立性压力与神经肌肉传递下降。红区暴露 >95% HRmax 时开始计时——每次超红区应有时间上限。每 5m 看 Burpee 节律是否掉线（单次耗时波动 >0.5s = 神经肌肉输出崩）。Run 5 是主动恢复段——降配速换 D' 恢复。

04 · Run 6 — Row → 第 6 跑

生理主题：心输出量天花板与血流竞争。心率封顶设 Run 1 均值 −5 bpm 或 88-90% HRmax。同配速下心率漂移 >5 bpm → 主动降功率。前 200m 用高步频冲刷跑，不急于回到巡航配速。

05 · Run 7 — Farmers Carry → 第 7 跑

生理主题：呼吸肌代谢反射。220+ spm 滑步走法，30-40cm 短步幅。4 步 1 呼吸周期——避免膈肌因稳定任务过度疲劳。上半身尽量减小垂直震荡，颈部放松。

06 · Run 8 + Finish — Lunges / Wall Balls → 终跑

生理主题：离心损伤与中枢疲劳。箭步蹲膝盖最后 5cm 有意识减速，避免砸地离心损伤。墙球用腿-髋-核心-手的动量传递完成，手臂仅在惯性顶点顺势推出，记录中断次数。Run 8 不硬追配速——除非 D' 还有余量。

教练决策框架：每站后看三点——① 配速是否在 CS×0.90-0.95 区间？② 心率是否拉回 LTHR 以下？③ D' 剩余是否足够完成后续站点的加速需求？三个答案全是"是"，你的策略就对了。

🎯 模拟后的三类输出靶点

① 速度靶点：下个训练周期的每段配速目标（精确到 ±3 秒/km）；② 心率封顶：各站点的出站心率上限 + 跑步段恢复目标心率；③ 站点动作节奏：每个功能站点的分段策略和中断容忍上限。公开课现场用这三类靶点反推训练模块设计。

各指标含义（每次比赛前回来看一眼）

核心

CS — 临界速度

你能无限维持的最高速度。CS 以下 = 不累垮。HYROX 里不能全程跑 CS——站点也需要能量。

  • CS ≈ 最大乳酸稳态
  • HYROX 巡航 ≈ CS × 0.95
  • 慢跑堆量 + 节奏跑 → CS↑
核心

D' — 无氧电池

高于 CS 时能额外跑的距离。站点后加速回配速就耗 D'。电池耗尽→掉速。

  • 耗尽时间 = D'/(速度−CS)
  • 低于 CS 跑 → D' 慢慢恢复
  • 短间歇 + 力量 → D'↑
心率

LTHR — 心率红线

约 60 分钟的最高心率。超过 = 进入倒计时。HYROX 里站点推高心率后，跑步段必须拉回 LTHR 以下。

  • 30 分钟法：后 20 分钟均值
  • 划船 LTHR ≈ 跑步 LTHR − 5
心率

HRR — 储备心率

考虑你个人静息心率的强度计算。公式：RHR + (MHR−RHR) × %。比单纯 % 最大心率更准。

  • 静息心率越低 → 窗口越宽
  • Z2 训练对此公式最敏感
权衡

CS vs D' 取舍

CS 和 D' 通常负相关——耐力型 CS↑/D'↓，冲刺型 CS↓/D'↑。训练需按项目距离分配比例。

质控

R² — 可信度

测试点拟合程度。≥0.98=可靠，0.95-0.98=可用，<0.95=重测。不稳定的原因：未全力跑 / 疲劳 / 条件不一致。
