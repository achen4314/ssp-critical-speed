各指标含义详解（新手必读）

核心指标

CS — 临界速度 (Critical Speed)

定义：你能理论上无限维持的最高跑步速度。

生理本质：此时身体产生乳酸 = 清除乳酸，乳酸不再累积，是可持续跑的边界线。

  • CS ≈ 最大乳酸稳态 (MLSS)
  • CS ≈ 马拉松/半马比赛配速
  • CS ≈ 最大心率 88-92%

怎么提升：慢跑堆量（线粒体↑）+ 节奏跑（乳酸清除↑）+ 长距离

核心指标

D' — 无氧距离储备 (Anaerobic Distance Reserve)

定义：高于 CS 时你能额外跑出的总距离，像一块"无氧电池"。

生理本质：磷酸原 + 糖酵解系统的总容量。速度超出 CS 越多，电池消耗越快。

  • 耗尽时间 t = D' / (当前速度 − CS)
  • 低于 CS 跑时，D' 缓慢恢复
  • 800/1500m 选手 D' 通常很大

怎么提升：短间歇冲刺 + 力量训练 + 高强度间歇（≥CS 的 2-4min 重复跑）

教练必读

CS 与 D' 的权衡关系

同一个运动员，CS 和 D' 往往负相关——你很难同时拥有极高的 CS 和极大的 D'。

  • 耐力型（如马拉松选手）：CS↑↑↑ / D'↓
  • 速度型（如 800m 选手）：CS↓ / D'↑↑↑
  • 全能型（极罕见，如 Jakob）：CS↑ / D'↑

训练必须根据项目距离权衡二者投入比例。

质量控制

R² — 拟合优度

定义：测试数据的线性拟合程度，范围 0-1。越接近 1 说明数据越可信。

  • R² ≥ 0.98：数据非常可靠，CS/D' 精确
  • 0.95 ≤ R² < 0.98：可用，有小波动
  • R² < 0.95：数据不稳定，建议重新测试

不稳定的原因：距离太接近、未全力跑、或测试间隔过短导致疲劳。

注意事项

测试必须遵守

  • 全力跑：每个距离都必须是当前的最大努力，不能"留力"
  • 充分休息：两次测试之间至少间隔 30-60 分钟
  • 标准化条件：尽量在同一跑道、相近天气下测试
  • 热身充分：每次测试前 10-15 分钟慢跑 + 动态拉伸
  • 定期重测：训练 8-12 周后重新测试以追踪进步
